## 寄存器

> **机器可读契约（文档生成工具依赖，写手册时必须遵守）**：
>
> - 寄存器章标题固定为 `## 寄存器`（英文手册为 `## Registers`），且必须是全文最后一章；
> - 每个寄存器一个三级标题，唯一合法形式 `### <中文名>(<REG_NAME>)`（如 `### 时间戳计数器(TSCTR)`）；
> - 每个寄存器必须含 `偏移地址：0x…` 与 `复位值：0x…` 两行（英文手册为 `Offset:` / `Reset value:`），缺一即解析失败；
> - 位域表表头固定为 `|位域|名称|读写属性|描述|`（英文手册为 `|Bits|Name|Access|Description|`），行格式 `|N 或 N:M|名称|读写属性|描述|`，`<br>` 表示换行；
> - `### 寄存器总览` 表只作交叉校验（offset 不一致仅告警，不报错）；RESERVED 行可留空读写属性。

**逐位域详细说明**（对齐 `full.md` 的粒度：每个位域一个小节，含名称行 + 描述 + 软件用法）：

**Bit 20 FIELD3：功能3使能**

> 示例行格式（必仿写）：功能3开关说明，本位上电后为 0。
>
> - 0: 功能3那样这样（默认行为描述）
> - 1: 功能3那样这样
>
> 软件用法：配置功能3时写 1；读取该位的值为 0 表示功能3未使能。

**Bit 12 FIELD2：功能2使能**

> 功能2方向选择。 - 0: 功能2那样这样 - 1: 功能2那样这样

**Bits 5:4 FIELD0：功能0配置**

> 两运行模式选择。复位值 01。
> - 00: 模式A（描述 A 行为）
> - 01: 模式B（描述 B 行为）
> - 10: 模式C（描述 C 行为）
> - 11: 保留，不得使用
> 软件用法：软件配置流程中“某场景”步骤里明确写要配 01。

**Bit 6 FIELD1：功能1标志（w1c）**

> 状态类位：硬件置位、软件写 1 清除。 - 0: 无事件 - 1: 事件发生（当事件发生时硬件自动置 1）
> 软件用法：每次事件处理后写 1 清除；复位后为 0。

**RESERVED**：全部保留位——固定“保留，必须保持复位值”，不描述软件用法。

读写属性 access 语义（参考 UVM，表内使用左侧缩写）：

```

ro  read-only
wo  write-only
w1  write-once
w1c write a 1 to bitwise-clear
rc  clear on read
rs  Read Sets All
wrc Write Read Clears All
wrs Write, Read Sets All
wc  Write Clears All
ws  Write Sets All
wsrc Write Sets All, Read Clears All
wcrs Write Clears All, Read Sets All
w1s Write 1 to Set
w1t Write 1 to Toggle
w0c Write 0 to Clear
w0s Write 0 to Set
w0t Write 0 to Toggle
w1src Write 1 to Set, Read Clears All

```
